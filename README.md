## Featured Projects 


### AgentFlow — RAG + AI/Human Task Orchestration Platform  
Repo: https://github.com/adrian2504/AgentFlow-Retrieval-Augmented-Intelligent-Work-Allocation-Dynamic-AI-Talent-Pairing-Platform  
- Converts a raw project brief into **atomic tasks**, maps dependencies, and routes each task to **AI vs. human** based on rules + skills/availability.
- Injects **retrieved context (RAG)** into both AI prompts and human briefs to reduce hallucinations and speed up execution.
- Streams task status in real time to a **Kanban dashboard** (Queued → In-Progress → Done) via WebSockets.
- Pluggable LLM layer (OpenAI-compatible endpoints) + local serving options for low-cost experimentation.

**Tech:** FastAPI, WebSockets, React/Vite, Tailwind, Chroma/pgvector, asyncio, Docker

### Smart Photo Library — Serverless Image Upload + AI Search (AWS)
Repo: https://github.com/adrian2504/Smart-Photo-Library-adrian  
- Built a photo library where users **upload images** and later **search by keywords** (e.g., “beach”, “city”, “sunset”).
- Uses **Rekognition** to auto-tag photos on upload and indexes metadata in **OpenSearch** for fast retrieval.
- End-to-end AWS workflow with **API Gateway + Lambda + S3 + CodeBuild + CloudFormation**, plus a lightweight static frontend on S3.

**Tech:** AWS (S3, Lambda, API Gateway, Rekognition, OpenSearch, CodeBuild, CloudFormation), Python, HTML/JS

---

### Dining Concierge — Lex Chatbot + Personalized Restaurant Recommendations (AWS)
Repo: https://github.com/adrian2504/Dining-Concierge-project-Deployed-Fully-on-AWS  
- Serverless chatbot that collects dining preferences (cuisine, date/time, party size, email) via **Amazon Lex**.
- Queues requests in **SQS**, fetches restaurant candidates from **OpenSearch**, then pulls full details from **DynamoDB**.
- Sends curated recommendations via **SES**, and stores “last search” state in DynamoDB for smarter follow-ups.

**Tech:** AWS (Lex, Lambda, API Gateway, SQS, DynamoDB, OpenSearch, SES), Python
